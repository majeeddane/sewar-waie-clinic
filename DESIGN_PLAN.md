### فكرة "شجرة الوعي المتحركة"

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│         🌳 SVG Path Drawing Animation                        │
│         "شجرة تتكوّن مع تمرير الصفحة"                        │
│                                                              │
│  ┌────────────────────────────────────────────────────────┐  │
│  │                                                        │  │
│  │    🍃          🌿                                     │  │
│  │      \        /                                       │  │
│  │       \  🌳  /    ← الشجرة تتكبر تدريجياً            │  │
│  │        \|/         مع كل قسم جديد                      │  │
│  │         │                                           │  │
│  │         │         ← الجذور تمثل الأساس والثبات        │  │
│  │        /|\                                          │  │
│  │       / | \         ← الجذور تكتمل في النهاية        │  │
│  │      /  |  \                                        │  │
│  │    🌙    ☾    🌙                                     │  │
│  │                                                        │  │
│  └────────────────────────────────────────────────────────┘  │
│                                                              │
│  الرمزية:                                                   │
│  • الشجرة = النمو والتعافي                                  │
│  • الجذور = الأساس والثبات (الوعي)                          │
│  • الأوراق = ثمار الرعاية                                   │
│  • الهلال = الهوية العربية                                  │
│  • النجمة = التميز والتفوق                                  │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### التقنية المستخدمة:
```typescript
// GSAP ScrollTrigger + SVG drawSVG effect
// الشجارة تبدأ صغيرة في Hero
// تكبر وتتفرع مع كل scroll
// تكتمل في Contact Section
```

### موضع الشجرة:
- **ثابت في الخلفية** (Position: Fixed) بـ opacity منخفض
- تظهر تدريجياً مع التمرير
- لا تتداخل مع المحتوى (z-index منخفض)
- تتحرك ببطء شديد (Parallax بطيء)

## 🎯 سادساً: قواعد صارمة للتنفيذ

### ❌ ممنوع:
1. **لا تكرر نفس تخطيط البطاقة** في أكثر من قسمين
2. **لا تستخدم روابط placeholder** (# أو javascript:void)
3. **لا تستخدم أيقونات Lucide الافتراضية** بدون تعديل
4. **لا تجعل جميع الخلفيات بيضاء**
5. **لا تستخدم أحجام خطوط متشابهة** (> 20% فرق بين H1-H2-H3)

1. **كل قسم له هوية بصرية مميزة**
2. **جميع الروابط تعمل فعلياً**
3. **الحركات هادئة وبطيئة** (Calm Premium)
4. **التباين الواضح بين الأقسام**
